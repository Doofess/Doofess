How I work

Sheet 06

My part

These projects are built with AI coding agents (Claude Code). In every one of them:

  • I make the design choices.
  • I make all the UX/UI decisions.
  • I read and review the code the agents write.
  • I test the apps by hand.

The workflow

  • Work runs in planned passes. A main session writes the plan, worker agents carry out the steps, and each result is checked and tested before the next step.
  • A pull request is merged only after a review. A hook refuses the merge until the latest commit has been reviewed.
  • Token use is kept low. The model is chosen per task and tools are switched on per project.
  • Sessions are run with the context window, turns and the prompt cache in mind.

The setup behind this is public: claude-setup.
